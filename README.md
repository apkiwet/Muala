**MUAPA – odkrywaj ciekawe miejsca na mapie!**

MUAPA to aplikacja mapowa, która pomaga odkrywać interesujące miejsca i lokale. Projekt powstał z myślą o osobach, które chcą łatwo znajdować ciekawe punkty na mapie.

## ✨ Funkcje

- 🗺️ Interaktywna mapa
- 📍 Lokalizacje ciekawych miejsc
- 🍽️ Odkrywanie interesujących lokali
- 📱 Aplikacja na Androida
- 🎨 Prosty i przejrzysty interfejs

## 📥 Pobierz MUAPA

Najnowszą wersję aplikacji na Androida znajdziesz w sekcji **Releases** tego repozytorium.

1. Otwórz sekcję Releases.
2. Wybierz najnowsze wydanie.
3. Pobierz plik `app-release.apk`.
4. Otwórz pobrany plik na telefonie.
5. Jeśli Android wyświetli ostrzeżenie, zezwól na instalację aplikacji z używanego źródła, jeśli ufasz plikowi.

**Uwaga:** MUAPA jest udostępniana poza Google Play. Instaluj aplikację wyłącznie wtedy, gdy ufasz źródłu pliku.

## 🛠️ Technologie

- Flutter
- Dart
- flutter_map
- OpenStreetMap / używane źródła map
